# 团队使用说明

## 放置方式

团队成员同步包含 `.agents/skills` 的项目目录后，在  项目中打开 Codex 即可使用。若成员需要跨项目调用，可把整个 Skill 文件夹复制到个人 Codex Skills 目录；复制时保持目录名不变。

## 需要交给团队成员的文件

如果团队成员使用同一份 Bubble 项目仓库，只需确保下列内容已同步：

```text
.agents/skills/bubble-story-event-guide-config/   # 整个目录，不能只发 SKILL.md
策划/配置表/剧情、事件AI配置/剧情事件需求池.xlsx
策划/配置表/剧情、事件AI配置/剧情事件AI配置工作流.md
策划/配置表/剧情、事件AI配置/剧情配置说明_给AI使用.md
策划/配置表/剧情、事件AI配置/事件配置说明_给AI使用.md
策划/配置表/新手引导AI配置/                   # 现有新手引导活动池与规则
```

最省事的交付方式是提交上述项目文件，让成员拉取同一仓库。若只能单独发包，应把整个 `bubble-story-event-guide-config` 文件夹原样打包；其中已包含规则快照和空白模板，但成员还需要项目当前的 `Table`、代码和 Prefab 才能生成可验证的正式项目草案。

## 首次使用：必须复制两个需求池

Skill 目录中的工作簿是初始化模板，不能直接在 `assets/templates/` 内长期填写。每个 Bubble 项目首次使用本 Skill 时，必须把下面两个表分别复制一份到项目配置目录，作为团队持续维护的活动需求池：

### 剧情 / 事件需求池

```text
复制来源：<Skill目录>/assets/templates/剧情事件需求池模板.xlsx
项目目标：D:\Bubble\策划\配置表\剧情、事件AI配置\剧情事件需求池.xlsx
相对路径：策划/配置表/剧情、事件AI配置/剧情事件需求池.xlsx
```

### 新手引导需求池

```text
复制来源：<Skill目录>/assets/templates/新手引导需求填写模板.xlsx
项目目标：D:\Bubble\策划\配置表\新手引导AI配置\新手引导需求池.xlsx
相对路径：策划/配置表/新手引导AI配置/新手引导需求池.xlsx
```

两个目标文件都需要存在，之后 AI 才能分别处理剧情 / 事件需求和新手引导需求。若目标路径已经有正在使用的需求池，直接沿用，**不得用模板覆盖**，以免清空团队历史需求和处理状态。

## 最短指令

```text
用 $bubble-story-event-guide-config 处理剧情事件需求池。
```

```text
用 $bubble-story-event-guide-config 处理新手引导需求池。
```

```text
用 $bubble-story-event-guide-config 处理所有待配置内容。
```

也可直接提交一句自然语言：

```text
用 $bubble-story-event-guide-config 配置：二楼修复后贵妇鹅出现，玩家点击后对话，结束后播放一段剧情。缺失值先做 A-假设草案。
```

## 成员填什么

- 剧情 / 事件：优先填活动池的“需求一句话”，触发、动作、对象和限制知道多少填多少。
- 新手引导：填“功能/界面”和“希望玩家学会什么”；补充要求和参考资料可选。
- 不要求成员填写内部 ID、枚举或 Prefab 路径。AI 应从当前表、代码和 Prefab 取证，无法验证时标记假设。

## 模板

`assets/templates/` 提供：

- `剧情事件需求池模板.xlsx`：剧情 / 事件长期活动需求池初始模板。
- `新手引导需求填写模板.xlsx`：新手引导需求表初始模板。

模板只用于首次复制，不在 Skill 目录内直接填写，也不覆盖项目中已有活动池。两个日常入口分别是：

- `D:\Bubble\策划\配置表\剧情、事件AI配置\剧情事件需求池.xlsx`
- `D:\Bubble\策划\配置表\新手引导AI配置\新手引导需求池.xlsx`

旧 `剧情事件AI输入模板/` 只作兼容资料。

## 审核顺序

1. 先看需求池的“AI假设/需要确认”。
2. 再看本次配置记录和 `generation-manifest.json`。
3. 查看受影响副本 Sheet 的预览，确认草案位置、字段和引用可追踪，并确认正式文件未被修改。
4. 策划确认动作、触发、文案和假设；客户端/测试确认代码事件、路径、存档、中断和实机结果。
5. 如需激活或导表，由人工/项目发布流程在确认后执行；本 Skill 不直接改正式区。

## 维护

规则源更新后运行：

```powershell
& ".\.agents\skills\bubble-story-event-guide-config\scripts\check_source_drift.ps1" -ProjectRoot "D:\Bubble"
```

若返回 `drift`，应更新 Skill 内的对应规则快照和模板，再执行 Skill 校验；不要让团队成员继续无提示地使用过期规则。
